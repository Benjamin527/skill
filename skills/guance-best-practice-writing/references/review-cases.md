# Review Cases

Use to resolve ambiguous reviews or validate changes to this skill. These are generalized cases from the accepted editorial requirements, not new universal requirements. During independent behavioral testing, provide the input column without revealing the expected decision first. Keep evaluation outputs outside the skill directory.

| Input | Expected decision |
|---|---|
| Twelve H2s, two embedded images, one whiteboard; otherwise strong verified implementation; imminent publishing deadline | Structure and image gates fail. Propose task-based consolidation and a meaningful additional image. A whiteboard does not replace the third image; deadline and prose quality do not waive the gates |
| Six H1 main sections, with subordinate H2 steps | Rebuild hierarchy by meaning within eight H2s; do not blindly change all headings to H2 or erase needed parent-child relationships |
| User permits text-only edits and requires preservation of two existing images | Finish text work; preserve image identities/order/anchors; deliver a draft with a specific missing-image note, without pretending a placeholder is an image |
| Three embedded AI illustrations and no platform result; source claims “实测接入成功” | Image count and proof are separate. Explain illustrations as design material; remove or qualify unsupported success and identify missing actual result evidence |
| Twenty-line `report.py`, a dashboard JSON template, and an uninspected third-party ZIP are attachments; user permits text-only edits | Script delivery is unresolved until repository migration/linking; keep resources intact within scope. Do not classify the JSON or unknown ZIP as custom scripts without evidence, push code, invent links, or silently remove attachments |
| A normal in-body command snippet and a valid existing versioned repository file link | No automatic script-attachment violation or unnecessary upload workflow; verify the existing asset is relevant and usable |
| Seven H2s and three images; five named SQL-operation alerts share a query without operation-type filtering | Format passes but technical semantics require substantive revision. Check scope with positive/negative samples; use `dql` for DQL work and distinguish checker success from scenario correctness |
| HTTP 200 and collector receipt are the only evidence for “全链路可观测” | Claim only the reached stage. Target-platform queryability/correlation remains unverified; do not invent screenshots or results |
| Valid TOML comments explain a verified sampling interval | May retain useful valid comments. Do not call it non-executable solely because it has comments; JSON uses different syntax rules |
| An accepted sample uses numbered headings and automatic subsection numbering | Learn its evidence progression, preserve the user's unnumbered default, inspect actual saved styles/TOC; retain meaningful technical numbers and sequential body actions |
| The current user explicitly requests numbered headings for this article | Preserve the requested numbering through final read-back; verify sequence and references instead of stripping it during cleanup |
| User asks to study a Feishu URL; body reads empty and a key embedded sheet is unavailable | Stay read-only. Try the resolved document/resource when useful, then report read limits and request the actual draft/access as necessary; no invented article or deletion claim |
| Immutable screenshot appears to expose a secret | Finish authorized text work, keep the resource ledger, identify the required sanitization as a publication blocker; do not publish or silently replace the image |
| A draft describes a service/host relationship, event matching tags, and extra context in one vague paragraph | Separate these roles with the actual field mapping and one traceable test; do not treat similar concepts as interchangeable |
| A migration article says all resources matching a name substring can be deleted; no rollback evidence | Require precise scope, data/consumer checks and rollback boundaries; editorial review does not authorize running deletion or recovery commands |

Passing these examples demonstrates specific behaviors, not universal reliability. Preserve concise output: article or requested review, plus unresolved material gaps when needed. Do not print this matrix in ordinary article deliveries.
